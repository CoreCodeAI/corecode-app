# Agent Note: Keep embedded reminders and model switch notes out of human text

Status: implemented

## Problem

After the clock reading fix shipped on 2026-11-06, two more refusals that day
suspended a user with an excerpt that was not the person's text:

- Record 160 (user 1193, `cyber`): one text block holding two
  `<system-reminder data-role=...>` blocks (an Agent mode prompt and the current
  time) followed by the person's `<user_query>`. `humanMessageText` skipped a
  reminder only when it was the whole block, so it kept the block, and the
  excerpt cut at the alert's 120 characters showed only the Agent mode prompt.
- Record 159 (user 1136, `cyber`): the whole excerpt was a client's note,
  `[model changed: assistant turns above this point were generated by
  mingtone/deepseek-v4.1-flash; the session continues with
  new11/claude-haiku-5-5]`, sent as a user message of its own.

The operator could not judge either refusal from its record. The same text is
the risk gate's latest message, so its regex and decision model read the client
text too.

## Decision

`humanMessageText` removes every complete `<system-reminder>` block, with or
without attributes, wherever it appears in a text block, and removes the model
switch note when it fills a whole line (`clientModelSwitch`). The note's only
variable parts are two model names without spaces or `;`, so removing a match
removes nothing a person wrote. A note with other text on its line stays. So
does a reminder without a closing tag.

## Alternatives considered

- **Keep the whole-block rule and add only the model switch note.** Record 160
  shows reminders before the person's text in the same block.
- **Pick the `<user_query>` element when present.** That covers one client.
  Removing reminders covers every client that injects them.

## Consequences

- A person could already hide text from the guard by sending it as a separate
  block wrapped in `<system-reminder>`. Removing embedded reminders lets them
  do the same inside a block, so it adds no new way to hide text. The
  upstream's own refusal still judges the whole request.
- Conversation keys of turns that held such reminders change, so a resend of a
  conversation blocked before this release no longer matches its block.
  Suspensions are unaffected.
- Excerpts already stored for records 159 and 160 stay as they are until they
  expire after 30 days.
